USB 设备

插在 ESP32 USB Host 口上的设备，可通过 USB/IP 网络共享给电脑

在电脑上怎么用这些设备？
Linux 客户端
sudo modprobe vhci-hcd
sudo usbip attach -r <设备IP> -b <busid>
busid 就是上表里的 1-1 这种。Windows 用 usbip-win2 图形客户端， 服务器填设备 IP、端口 3240。完整步骤见 项目主页

WiFi 设置

连上才保存，失败保持原配置（最长等 15 秒）

连不上本页时：走串口救急
配错 WiFi 连不上本页时，走串口救急
用 USB 转 TTL 串口线（115200，GND 共地）接配置口，终端里执行：
wifi_set MyAP 12345678
help 看全部命令；<SSID> [password] 只是占位记号，输入时不带
TTL 的 RX → 本机 TX 脚：GPIO
TTL 的 TX → 本机 RX 脚：GPIO
串口救急不可用
配置口 UART 没编译进本固件（Kconfig 的 USBIPD_CFG_CONSOLE_ENABLE 关闭）， 需重新编译开启，或先换一个能连上的 WiFi 再回来配置

配网热点—

连不上 WiFi（或工作模式设为 AP，见 WiFi 页）时自动开启， 连上它访问 192.168.4.1 即可配网
